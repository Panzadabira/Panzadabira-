# Panzadabira-

👋 Hello, I'm Jonathan Barenco (Panzadabira)

Indie game developer, and founder of Panza Labs. I build tools that remove the friction from game development, specializing in LLM-driven architectural analysis and automated CI/CD workflows.



🧬 The Panza Labs Philosophy

Panza Labs was born in August 2025 from a simple, personal necessity. Before I wrote a single line of code, I was just a gamer who lived for complex mechanics and tabletop strategy. When I finally made the leap to become a solo indie developer, I quickly hit the classic wall: I was spending more time battling messy architecture, broken workflows, and repetitive tasks than actually designing my games.

I realized that to survive the indie grind—and to keep the development of my own projects like Wildroots and SaniDex actually fun—I had to simplify my life. I started building my own custom tools just to automate the boring stuff and untangle the code. What began as personal survival gear to save my own sanity quickly evolved into high-end DevTools. My products aren't just theoretical; they are forged in the trenches of my own gamedev journey, built by an indie developer for indie developers to solve real-world plumbing headaches.

Game development should be about creativity. Let the tools handle the rest.



🛠️ Flagship Product: PanzaScope

PanzaScope is a universal polyglot static analysis engine designed to perform zero-latency architectural mapping of complex codebases.

PanzaScope (Engine): Open-source static analysis engine for polyglot codebases (Python/Standalone).

PanzaScope (Unity Extension): Native C#/UI Toolkit integration for professional Unity pipelines. Available for 42.00 CHF.



⚡ Tech Stack & Focus

Gamedev: Unity, C#, UI Toolkit, ScriptableObject-driven architecture.

Automation: Python, Multi-agent AI systems (The Panza Agency suite).

Architecture: Static Analysis, Context Compression for LLMs (Eco-Scan protocol).
