# Hi, I'm Jonathan Barenco (Panzadabira) 

**Indie Game Developer & Founder of Panza Labs**
> *I build tools that remove the friction from game development, specializing in LLM-driven architectural analysis and automated workflows.*

---

##  The Panza Labs Philosophy

Panza Labs was born in August 2025 from a simple, personal necessity. Before I wrote a single line of code, I was just a gamer who lived for complex mechanics and tabletop strategy. When I finally made the leap to become a solo indie developer, I quickly hit the classic wall: **I was spending more time battling messy architecture, broken workflows, and repetitive tasks than actually designing my games.**

I realized that to survive the indie grind and keep the development of my own projects like *Wildroots* and *SaniDex* actually fun, I had to simplify my life. I started building my own custom tools just to automate the boring stuff and untangle the code. What began as personal survival gear to save my own sanity quickly evolved into high-end DevTools. 

My products aren't just theoretical; they are forged in the trenches of my own gamedev journey—**built by an indie developer for indie developers to solve real-world plumbing headaches.**

>  *"Game development should be about creativity. Let the tools handle the rest."*

---

##  Flagship Product: PanzaScope
**Universal Polyglot Static Analysis & Architectural Mapping Engine**

Stop feeding raw scripts to your LLMs. PanzaScope visualizes complex dependencies in milliseconds and extracts logic-stripped JSON blueprints, preventing context window saturation and token waste.

*  **PanzaScope (Engine):** Open-source static analysis engine for polyglot codebases (Python / Standalone).
*  **PanzaScope (Unity Extension):** Native C# / UI Toolkit integration for professional Unity pipelines with Hot-Reload and Inspector Ping.
